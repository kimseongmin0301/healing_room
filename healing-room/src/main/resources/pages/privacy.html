2. 다른 사람에게 보이는 것

  • 같은 방 사람에게: 닉네임, IP 앞부분(예: 203.0.*.*), 들어온 지 얼마나 됐는지, 방장 표시, 채팅 메시지
  • 방문자 번호와 전체 IP 는 다른 방문자에게 보이지 않아요. 전체 IP 는 장난·공격 대응을 위해 운영자만 볼 수 있어요.

욕설·음란어 제한: 채팅·닉네임·방 이름에 욕설이나 음란한 말이 있으면 그 IP 와 방문자 번호로 30분 동안 채팅·방 만들기·방 입장을 막아요. PC방·회사처럼 IP 를 같이 쓰는 곳에서는 옆 사람도 함께 막힐 수 있어요. 잘못 막혔다면 첫 화면 아래 의견 보내기로 알려 주세요.

3. 브라우저에 저장하는 것

아래 값은 서버가 아니라 내 브라우저에만 있어요. 브라우저의 사이트 데이터 삭제로 언제든 지울 수 있어요.

  • hr_vid (쿠키), visitorId (저장소): 방문자 번호
  • chatNickname: 채팅 닉네임
  • myRequests: 내가 신청한 곡 기록(최대 100곡, 내 추천에만 사용)
  • musicOn · ambientOn · musicVolume: 소리 켜기·끄기, 음량
  • musicView · chatCollapsed: 음악 창 크기, 채팅 창 접기
  • ambientWithMusic: 음악과 함께 환경음 듣기
  • _ga, _ga_* (쿠키): Google Analytics 가 같은 브라우저의 재방문을 세는 무작위 번호 (최대 2년)

4. 함께 쓰는 외부 서비스

  • YouTube (Google): 음악은 YouTube 플레이어로 재생해요. 재생할 때 Google 이 자체 쿠키 등으로 정보를 모을 수 있고, 이는 Google 개인정보처리방침을 따라요. 노래를 검색하면 검색어만 YouTube 로 보내요(방문자 정보는 보내지 않음).
  • Google Analytics (Google): 방문 통계를 위해 페이지를 볼 때 위 1번 표의 정보가 Google 로 가요. Google 이 이 정보를 쓰는 방법. 원하지 않으면 브라우저에서 쿠키를 막거나 Google Analytics 차단 부가기능을 쓰면 돼요. 막아도 힐링룸은 그대로 쓸 수 있어요.
  • 카카오페이: 서버비 후원 버튼의 QR 이나 링크를 직접 눌렀을 때만 카카오페이로 이동해요.
  • 그 밖에 다른 회사에 정보를 주거나 팔지 않아요.

5. 지우고 싶을 때

  • 내 브라우저에 있는 정보: 브라우저 설정에서 이 사이트의 쿠키·사이트 데이터를 지우면 돼요.
  • 서버에 남은 채팅·의견·신청곡 기록: 첫 화면 아래 의견 보내기나 아래 연락처로 방 이름, 대략의 시각, 내용을 알려 주면 찾아서 지워요.

6. 안전하게 지키는 방법

  • 모든 연결은 HTTPS 로 암호화해요.
  • DB 와 Redis 는 비밀번호가 있는 이 서비스 전용 계정으로만 쓰고, 운영자 화면은 로그인과 관리자 키 두 단계로 잠가 둬요.
  • 채팅·의견은 글자 그대로만 보여 주고 HTML 로 해석하지 않아요.
