힐링룸 소개

힐링룸은 화면을 켜두고 멍하니 쉬는 무료 웹 서비스예요. 불멍, 바다멍, 비 오는 숲, 우주 같은 테마 방에 들어가면 실사 배경이 천천히 움직이고 환경음이 흐르며, 같은 방 사람들과 YouTube 음악을 같은 곡·같은 위치로 함께 들어요. 회원가입과 로그인이 없어요.

이렇게 써요

  1. 방 고르기 첫 화면에서 테마 방을 누르거나, 방 만들기에서 이름과 테마를 골라 새 방을 만들어요.
  2. 소리 켜기 화면을 한 번 누르면 음악과 환경음이 나와요. 각각 따로 켜고 끌 수 있어요.
  3. 음악 신청하기 음악 창 아래 칸에 노래 제목을 검색하거나 YouTube 링크를 붙여 넣어 신청해요.
  4. 함께 쉬기 같은 방 사람들과 같은 음악을 듣고, 채팅으로 이야기해요. 방 주소를 친구에게 보낼 수도 있어요.

숫자로 보는 힐링룸

  • 테마 방 10가지, 모두 항상 열려 있어요
  • 브라우저에서 만드는 환경음 12가지 (장작, 비, 파도, 시냇물, 풀벌레, 천둥, 바람, 도시, 갈매기, 정거장 소리, 우주의 화음, 라운지 비트)
  • 같은 음악을 듣는 사람 사이의 차이는 최대 약 3초
  • 사용자가 만든 방은 아무도 없는 채로 30분이 지나면 닫혀요

같은 음악을 어떻게 함께 듣나요?

영상을 서로 주고받지 않고, 서버가 "이 곡이 몇 시에 시작했는지" 시각 하나만 알려 줘요. 각자 브라우저가 지금 위치 = 현재 시각 − 시작 시각을 계산해서 틀고, 컴퓨터마다 다른 시계는 서버 시각으로 보정해요. 5초마다 확인해서 3초 넘게 어긋나면 다시 맞춰요.

소리는 어떻게 만드나요?

환경음은 녹음 파일을 쓰지 않고 브라우저의 Web Audio 로 실시간 합성해요. 예를 들어 풀벌레 소리는 아주 짧은 "찍" 소리 여러 개를 높이와 박자, 거리가 다른 여러 마리로 겹쳐 만들어요. 그래서 반복 구간이 없고 파일을 내려받을 필요도 없어요.

개인정보

  • 회원가입·로그인이 없고, 브라우저마다 무작위 방문자 번호를 만들어 이 브라우저에만 저장해요.
  • 접속자 목록에는 닉네임과 IP 앞부분만(예: 203.0.*.*) 보여요. IP 는 저장하지 않고 접속해 있는 동안 서버 메모리에만 둬요.
  • 채팅은 방마다 최근 100개만 보관하고, 사용자가 만든 방은 닫힐 때 함께 지워요.

만든 사람

개인 개발자가 만들고 운영해요. 소스 코드는 GitHub 에 공개되어 있어요. 기술: Java 17, Spring Boot, PostgreSQL, Redis, WebSocket, Canvas, Web Audio, YouTube IFrame Player API.
